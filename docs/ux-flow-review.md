# 화면 흐름 점검과 배치 정리

"좌우 영역이 일관성 없이 나뉘어 있어 어디를 봐야 할지, 어디서 찾아야 할지 모르겠다"는 문제를 기준으로 가공 화면의 사용 흐름을 점검하고 배치를 다시 정리했습니다.

## 1. 실제 사용 순서

화면에서 한 번의 가공 검토는 다음 순서로 진행됩니다. 공구·원소재를 고르면 바로 프로필에 반영되고 절삭 조건도 다시 산정됩니다. 냉각은 고르는 즉시 프로필에 반영됩니다.

1. 프로필 고르기 (또는 프리셋으로 새로 만들기)
2. 공구 바꾸기 / 직접 만들기
3. 원소재 바꾸기 / 직접 만들기
4. 냉각 방식과 세부값, 작업장 온도·습도 정하기
5. 절삭 조건 계산 → 결과 확인 → 프로필에 적용
6. 가공 경로를 고르고 재생 (계산 → 재생 → 열·깊이·마모 표시 → 2차 보정)
7. G-code·경고·로그 확인과 저장

## 2. 정리 전 상태에서 찾은 문제

| # | 문제 | 예 |
| --- | --- | --- |
| 1 | 같은 항목이 여러 곳에 흩어져 있음 | 냉각은 3곳(왼쪽 목록, 오른쪽 '냉각 설정', 계산 입력), 환경 2곳(오른쪽 '파라미터', 상단 '모델·환경'), 재생 버튼 2곳(툴바, 왼쪽 '애니메이션'), 프로필 요약 2곳 |
| 2 | 좌우를 나누는 기준이 없음 | 왼쪽에 목록과 재생 버튼이 섞여 있고, 오른쪽에 요약·계산기·냉각 설정·공구/원소재 만들기 폼이 섞여 있음. 공구는 왼쪽에서 고르고 오른쪽에서 만듦 |
| 3 | 메뉴를 누르면 패널 내용이 다시 펼쳐짐 | 상단 '설정'은 별도 화면이 아니라 좌우 아코디언을 다른 조합으로 펼침. 같은 내용도 누른 메뉴에 따라 보이는 위치가 달라지고, 실제 설정 화면인 '모델·환경'과 이름도 겹침 |
| 4 | 순서와 현재 값이 안 보임 | 단계 번호가 없고, 접힌 섹션은 무엇이 선택됐는지 보이지 않아 매번 펼쳐 봐야 함 |
| 5 | 툴바 순서가 작업 순서와 다름 | 재생 버튼을 지나 맨 뒤에서 가공 경로를 고르게 되어 있음 |
| 6 | 빈 섹션 / 버튼 하나뿐인 섹션 | '프로젝트'는 내용 없음, '리셋'은 버튼 하나 |
| 7 | 섹션 안쪽 배치도 제각각 | 2열·3열 격자와 간격이 섞여 있음. 계산은 '적용' 버튼이 결과보다 먼저 나옴 |

## 3. 바꾼 배치 규칙

```text
┌ 상단: 가공 · 정밀 분석 · 참고 자료 · 환경·모델 설정 ─────────────────────┐
├ 왼쪽 「준비」──────┬ 가운데 ───────────────────────┬ 오른쪽 「조건」 ─────┤
│ 무엇으로 깎을지     │ ⑥ 경로 → 재생 → 2차 보정 →     │ 어떻게 깎을지       │
│ ① 프로필           │    표시 토글 · 시점(피트/리셋)  │ 현재 구성 요약      │
│ ② 공구             │                                │ ⑤ 절삭 조건         │
│ ③ 원소재           │        시뮬레이션 뷰포트        │   입력 → 계산 실행  │
│ ④ 냉각 · 환경      │                                │   → 결과 → 적용     │
├────────────────────┴────────────────────────────────┴──────────────────────┤
│ ⑦ 출력: G-code · 경고 · 로그 · 프로필                                       │
└────────────────────────────────────────────────────────────────────────────┘
```

- **영역별 역할을 하나로 고정**: 왼쪽은 '무엇으로'(구성), 오른쪽은 '어떻게'(조건), 가운데는 실행과 보기, 아래는 결과물입니다. 번호 ①→⑦이 읽는 순서입니다.
- **한 항목은 한 곳에만**: 공구 목록·사양·공구 상태·커스텀 공구 만들기는 모두 ②에, 원소재 목록과 만들기는 ③에, 냉각 방식·세부값·작업장 환경은 ④에 있습니다. 프로필 요약은 오른쪽 '현재 구성' 하나만 남겼습니다.
- **접어도 현재 값이 보임**: 단계 머리글 오른쪽에 지금 고른 값이 표시됩니다(예: `② 공구 … 초경 4날 스퀘어 · Ø10 4날`). 펼친 단계는 번호 칩이 파랗게 바뀝니다.
- **메뉴를 바꿔도 패널은 그대로**: 별도 화면이 아니던 '설정' 메뉴를 없애고 실제 설정 화면을 '환경·모델 설정'으로 이름을 바꿨습니다. 정밀 분석·참고 자료·설정 화면은 가운데에만 열리고 좌우 패널은 펼침 상태 그대로 유지됩니다.
- **툴바 두 줄**: 첫째 줄은 실행 순서(⑥ 경로 → 재생·정지·속도·위치 → 2차 보정 →), 둘째 줄은 보기(표시 토글 → 시점 피트·리셋 → 경로 정보)입니다. 좁은 화면에서는 각 줄이 자기 안에서만 줄바꿈되어 실행과 보기가 섞이지 않습니다.
- **패널 제목줄 고정**: 좌우 패널 맨 위의 제목줄(「준비」·「조건」과 접기 버튼)은 고정되고 단계 목록만 스크롤됩니다.
- **안쪽 격자와 버튼 통일**: 모든 입력은 같은 2열 격자를 쓰고, 한 섹션 안에서는 입력 → 실행 → 결과 → 적용 순서로 놓았습니다. 채운 파란 버튼은 실행·적용, 테두리 버튼은 보조 동작과 만들기입니다.

## 4. 바뀐 동작

- 상단 '설정' 메뉴 제거. 그 메뉴가 펼치던 내용(공구·원소재·냉각 목록과 만들기 폼)은 왼쪽 ②–④에 항상 있습니다.
- 왼쪽 '애니메이션'·'리셋' 섹션 제거. 재생은 툴바 ⑥, 시점 리셋은 툴바 둘째 줄에 있습니다(뷰포트 더블클릭도 그대로).
- 빈 '프로젝트' 섹션 제거. ① 프로필의 '프로젝트 관리 →'를 누르면 정밀 분석 ⑦ 라이브러리 탭이 열립니다.
- 냉각 방식은 ④의 목록에서 고릅니다(누르면 기본 압력·유량으로 바로 적용). 세부값 폼에 있던 같은 기능의 방식 선택칸은 숨겼습니다.
- 절삭 조건 계산의 '프로필 값으로'는 계산 입력 제목 옆 링크로 옮겼고, '추천 조건을 프로필에 적용'은 계산 결과 아래로 옮겼습니다.
- 계산 맥락 상자는 '현재 구성' 요약과 내용이 겹쳐 숨겼습니다.

## 5. 확인한 것과 남은 것

- 백엔드 없이 띄운 화면에 임시 프로필 값을 넣어 확인했습니다: 단계 요약 표시, 단계 펼침/접힘, 커스텀 공구 폼 열기, 설정 화면 전환 시 패널 유지, '프로젝트 관리 →' 이동, 좌측 패널 접기/복원, 1600×900·1280×720 툴바 배치. 콘솔 오류는 없었습니다.
- 실제 앱에서 실제 데이터로는 아직 확인하지 않았습니다. 특히 단계 요약 문구(원소재 이름·재질 표기 길이 등)는 실제 값으로 한 번 더 봐야 합니다.
