# 엔드밀 샌드박스 개발 배경과 문제 해결 과정 정리해봤습니다

엔드밀 샌드박스는 CNC 기계에서 금속을 깎는 회전 공구 '엔드밀'이 어떤 조건에서 얼마나 힘을 받고, 뜨거워지고, 닳는지를 컴퓨터 안에서 미리 돌려 보는 가상 가공 시뮬레이터입니다.

- 공구·소재 조합: 공구 모양·코팅과 깎을 소재(알루미늄, 스테인리스, 티타늄 등)를 골라 조합
- 절삭 조건 추천: 회전수와 이송 속도를 물리 공식으로 계산
- 가공 시뮬레이션: 가공 경로를 따라 힘·열·마모를 한 걸음씩 계산
- 판단 도움: 공구 교체 시점과, 치수를 맞추려고 한 번 더 깎을지 여부를 제안

■ 프로젝트 내용 · □ 개인 생각

## 왜 만들었나

■ 정밀 가공에서 가장 무서운 건 공구가 조금씩 닳는 것입니다. 날이 닳으면 같은 프로그램으로 깎아도 벽 치수가 수 µm씩 틀어지고, 표면이 거칠어지고, 열과 떨림이 커집니다. 금형이나 정밀 부품은 이 몇 µm 차이로 불량이 되고, 심하면 공구가 부러져 소재까지 망가집니다.

■ 그래서 현장에서는 '언제 공구를 바꿀지, 한 번 더 깎아 치수를 맞출지'를 늘 판단해야 합니다. 너무 일찍 바꾸면 공구값이 낭비되고, 늦으면 제품이 망가집니다. 실제로 시험하려면 공구·소재·기계 시간·측정 장비가 들고, 공구·소재·냉각·조건 조합마다 결과가 다릅니다.

■ 엔드밀 샌드박스는 깎기 전에 이 조합을 가상으로 돌려 마모가 언제 한계에 닿는지, 치수가 얼마나 틀어지는지 미리 보려는 도구입니다.

□ 실제 공구와 측정 장비 없이 시작해서, 숫자 하나하나를 공개된 측정 자료에 맞춰 보는 데 가장 많은 시간을 썼습니다.

## 어떤 문제가 있었고, 어떻게 풀었나

### 1. 모든 조합에 같은 숫자를 쓰던 문제

■ 처음엔 마찰 정도나 처음 닳는 양 같은 값이 공구·소재가 바뀌어도 거의 같았습니다. 예를 들어 열처리된 금형강을 깎을 때 날끝 온도가 745 °C로 나와, 공개된 측정 범위(350~600 °C)를 벗어났습니다.

■ 소재별 측정 자료로 기준값을 만들고 코팅·공구 고정 방식 같은 차이는 작은 보정으로만 얹었더니 542 °C로 범위 안에 들어왔습니다. 근거가 약한 값은 '신뢰도 낮음'으로 따로 표시합니다.

### 2. 깎았는데 허공으로 계산되던 문제

■ 소재를 작은 칸으로 나눠 깎인 양을 세는데, 칸 한가운데만 확인하다 보니 깎는 구간의 절반이 허공으로 잡혔습니다. 알루미늄 예시에서 25.7초 걸릴 가공이 12.9초로, 옆으로 깎는 폭 0.50 mm가 0.99 mm로 계산됐습니다.

■ 공구가 칸을 얼마나 덮는지 비율로 세도록 바꿔 두 값 모두 제자리로 돌아왔습니다.

### 3. 공구 흔들림을 크게 읽던 문제

■ 공구가 돌 때 생기는 미세한 흔들림 값을 실제보다 크게 해석해, 순간 힘이 평균의 4배 넘게 튀었습니다.

■ 고친 뒤에는 흔들림 때문에 벽이 조금 더 깎이는 양과 벽면 거칠기까지 계산합니다. 실제 정삭면이 이론보다 19~38배 거친 이유가 이 흔들림이라는 연구 결과와도 맞습니다. 공구마다 수명이 들쭉날쭉한 정도도 넣어, 교체까지 남은 개수를 보수적으로 잡을 때 중간값보다 겨우 3% 낮던 값이 실제 편차만큼 넉넉해졌습니다.

### 4. 결과를 믿어도 되는지 알기 어려운 문제

■ 계산할 때마다 어떤 값을 썼고 어디가 앞뒤가 안 맞는지 점검 기록을 남깁니다. 결과는 바꾸지 않고 의심할 곳만 알려줍니다.

■ 재료를 작은 입자로 쪼개 직접 깎아 보는 두 번째 계산으로 교차 확인합니다. 스테인리스에서 공식 계산은 186, 입자 계산은 187~194(N/mm)로 비슷했습니다. 실험 검증 전이라 켤 때만 반영하고, 실제 측정값이 있으면 늘 측정값이 우선입니다.

### 5. 화면에서 길을 잃던 문제

■ 기능이 늘면서 냉각·환경·재생 버튼이 왼쪽, 오른쪽, 위쪽에 흩어져 어디를 봐야 할지 알기 어려웠습니다.

■ 왼쪽은 '무엇으로 깎을지'(①프로필 ②공구 ③원소재 ④냉각·환경), 오른쪽은 '어떻게 깎을지'(⑤절삭 조건), 가운데는 ⑥시뮬레이션, 아래는 ⑦결과물로 나누고, 접어 둔 단계에도 지금 고른 값이 보이게 했습니다. 화면은 회색 단계로 줄이고, 색은 마모·깊이처럼 봐야 할 값에만 남겼습니다.

## 마무리하면서

□ 처음엔 '공구도 측정 장비도 없이 마모를 다루는 게 의미가 있나' 싶었습니다. 그런데 숫자마다 근거를 찾고 틀린 곳을 고치다 보니, 실제 측정값이 들어왔을 때 어디부터 맞춰 보면 되는지가 오히려 분명해졌습니다.

□ 앞으로는 휴대폰 카메라로 저속 회전 중인 공구를 찍어 실제 마모와 비교해 보고 싶습니다. 아직 실험으로 검증되지 않은 시뮬레이션이라 가공 현장 경험이 있으신 분들이 이상한 부분을 알려주시면 정말 큰 도움이 됩니다. 읽어주셔서 감사합니다.
