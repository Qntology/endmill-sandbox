# 엔드밀 샌드박스 개발 배경과 문제 해결 과정 정리해봤습니다

엔드밀 샌드박스는 CNC 기계에서 금속을 깎는 회전 공구인 '엔드밀'이 어떤 조건에서 얼마나 힘을 받고, 얼마나 뜨거워지고, 얼마나 닳는지를 컴퓨터 안에서 미리 돌려 보는 가상 가공 시뮬레이터입니다.

- 공구·소재 조합: 공구 모양과 코팅, 깎을 소재(알루미늄, 스테인리스, 티타늄 등)를 골라 조합
- 절삭 조건 추천: 회전수와 이송 속도를 물리 공식으로 계산해 추천
- 가공 시뮬레이션: 6가지 가공 경로를 따라 힘·열·마모를 한 걸음씩 계산
- 환경 반영: 실내 온도·습도와 냉각 방식(절삭유, 에어, 미스트 등)
- 사진·추세 분석: 공구 사진을 이미지 AI로 비교하고, 마모 추세를 예측 모델로 내다봄
- 판단 도움: 공구 수명과 교체 시점, 한 번 더 깎아 치수를 맞출지 여부를 제안

■ 프로젝트 내용 · □ 개인 생각

## 왜 만들었나

■ 공구 마모를 실제로 시험하려면 이벤트 카메라(밝기가 바뀌는 순간만 아주 빠르게 기록하는 특수 카메라), 엔드밀과 공작물, 현장 전문성이 필요한데 셋 다 없었습니다.

■ 그래서 가상 시뮬레이션으로 시작하되, 온도·습도, 공구 형태와 코팅, 소재 형태와 재질, 냉각 방식 같은 환경 요소를 하나씩 조사해서 넣었습니다.

■ 공구 브랜드 이름은 저작권 문제로 쓰지 않고, 공구 모양과 코팅 소재만 프리셋으로 담았습니다.

□ 언젠가 실제 공구를 쓸 수 있게 되면 휴대폰 카메라로 이어 가 보고 싶습니다. 가공 중 원하는 순간에만 회전을 1000 RPM 근처로 낮춰 공구를 찍고, 깊이 추정과 형태 분리 AI로 처음 모습을 기준 삼아 달라지는 부분을 쌓아 보는 구상입니다. 아직은 가설에서 끝날 가능성이 큽니다.

## 어떤 문제가 있었고, 어떻게 풀었나

### 1. 모든 조합에 같은 숫자를 쓰던 문제

■ 처음에는 마찰 정도나 초기 마모량 같은 값이 공구·소재가 바뀌어도 거의 같았습니다. 소재별로 공개된 측정 자료를 찾아 기준값을 만들고, 코팅이나 공구를 잡는 방식 같은 차이는 작은 보정으로만 얹었습니다.

■ 직접 측정한 근거가 없는 값은 '신뢰도 낮음'으로 따로 표시합니다.

### 2. 깎았는데 허공으로 계산되던 문제

■ 소재를 작은 칸으로 나눠 깎인 양을 세는데, 칸 한가운데만 확인하다 보니 실제로 깎은 구간의 절반이 허공으로 잡혀 가공 시간이 절반으로 나오기도 했습니다. 공구가 칸을 얼마나 덮는지 비율로 세도록 바꿨습니다.

### 3. 흔들림을 크게 읽던 문제

■ 공구가 돌 때 생기는 미세한 흔들림 값을 실제보다 크게 해석해서, 한 번에 깎이는 두께와 힘이 부풀려져 있었습니다. 고친 뒤에는 흔들림 때문에 벽이 조금 더 깎이는 양, 벽면 거칠기, 같은 공구라도 수명이 들쭉날쭉한 정도까지 반영했습니다.

### 4. 결과를 믿어도 되는지 알기 어려운 문제

■ 계산할 때마다 어떤 값을 썼고 어디가 앞뒤가 안 맞는지 적어 두는 점검 기록을 남깁니다. 결과를 바꾸지는 않고, 의심해 볼 곳만 알려줍니다.

■ 공식 계산과 별개로, 재료를 작은 입자로 쪼개 직접 깎아 보는 두 번째 계산으로 교차 확인합니다. 실험으로 검증된 계산은 아니라서 사용자가 켤 때만 반영하고, 실제 측정값이 있으면 항상 측정값이 우선입니다.

### 5. 화면에서 길을 잃던 문제

■ 기능이 늘면서 냉각, 환경, 재생 버튼 같은 항목이 왼쪽·오른쪽·위쪽에 흩어져 어디를 봐야 할지 알기 어려웠습니다.

■ 왼쪽은 '무엇으로 깎을지'(①프로필 ②공구 ③원소재 ④냉각·환경), 오른쪽은 '어떻게 깎을지'(⑤절삭 조건), 가운데는 ⑥시뮬레이션, 아래는 ⑦결과물로 나누고 번호를 붙였습니다. 항목마다 자리를 한 곳으로 정했고, 접어 둔 단계에도 지금 고른 값이 보입니다.

## 마무리하면서

□ 처음에는 '공구도 카메라도 없이 마모를 다루는 게 의미가 있나' 싶었습니다. 그런데 숫자 하나하나 근거를 찾고 틀린 곳을 고치다 보니, 나중에 실제 측정값이 들어왔을 때 어디부터 맞춰 보면 되는지가 오히려 분명해졌습니다.

□ 아직 실험으로 검증되지 않은 시뮬레이션이라 정답이라고 말할 수는 없습니다. 가공 현장 경험이 있으신 분들이 보시고 이상한 부분을 편하게 알려주시면 정말 큰 도움이 됩니다. 읽어주셔서 감사합니다.
